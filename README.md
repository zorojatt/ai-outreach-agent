# AI Outreach Agent

Private AI-powered outreach assistant built with Next.js, TypeScript, Supabase, Gmail OAuth, AI providers, and configurable search.

## Status
Initial implementation started.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase PostgreSQL
- OpenAI/Gemini provider abstraction
- Gmail API OAuth 2.0

## Setup
See environment variables in `.env.example`.
